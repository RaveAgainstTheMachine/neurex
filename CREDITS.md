# 📜 Neurex Credits

Neurex is built on the shoulders of giants. This document lists the primary technologies, libraries, and frameworks that make the Universal Sentient IDE Substrate possible.

---

## 🚀 Core Engine & Substrate
- **[FastAPI](https://fastapi.tiangolo.com/)**: High-performance Python web framework for the Sentient Core.
- **[SQLModel](https://sqlmodel.tiangolo.com/)**: Database interaction layer combining SQLAlchemy and Pydantic.
- **[Structlog](https://www.structlog.org/)**: Structured logging for all architectural telemetry.
- **[Pydantic](https://docs.pydantic.dev/)**: Data validation and settings management.
- **[Asyncio](https://docs.python.org/3/library/asyncio.html)**: Asynchronous I/O for concurrent agent execution.

## 👁️ Glassmorphic Frontend
- **[React](https://reactjs.org/)**: Declarative UI library for the Glassmorphic interface.
- **[Vite](https://vitejs.dev/)**: Next-generation frontend tooling.
- **[Zustand](https://github.com/pmndrs/zustand)**: State management for the Neural Mesh Hub.
- **[Monaco Editor](https://microsoft.github.io/monaco-editor/)**: The world's most advanced code editor for the web.
- **[Framer Motion](https://www.framer.com/motion/)**: Production-ready animation library for fluid UI transitions.
- **[Lucide React](https://lucide.dev/)**: Beautiful & consistent iconography.
- **[dnd-kit](https://dndkit.com/)**: Accessible drag-and-drop toolkit for workspace orchestration.
- **[Xterm.js](https://xtermjs.org/)**: Integrated terminal emulation.

## 🧠 Neural Intelligence & Infrastructure
- **[llama.cpp](https://github.com/ggerganov/llama.cpp)**: High-performance LLM inference in C/C++.
- **[Ollama](https://ollama.ai/)**: Local AI model orchestration and management.
- **[Tree-sitter](https://tree-sitter.github.io/tree-sitter/)**: Incremental parsing for the Neural Lens and Linter.
- **[ChromaDB](https://www.trychroma.com/)**: AI-native open-source embedding database for the Hive Mind.
- **[Sentence-Transformers](https://sbert.net/)**: Semantic similarity and embedding generation.
- **[MCP (Model Context Protocol)](https://modelcontextprotocol.io/)**: Open standard for AI tool integration.

## 🛠️ Development & Quality
- **[Ruff](https://github.com/astral-sh/ruff)**: Extremely fast Python linter and formatter.
- **[TypeScript](https://www.typescriptlang.org/)**: Strict type safety across the entire frontend.
- **[Pytest](https://docs.pytest.org/)**: Robust testing framework for the API and agents.
