# Welcome to the Neurex Wiki

**Neurex** is an autonomous workspace designed for the neural era. It combines a high-performance Rust core with a decentralized mesh of AI agents to manage your codebase, optimize your hardware, and automate your engineering workflow.

- **[[Architecture]]**: How the Orchestrator, TaskGraph, and **Agentic Mesh** work together.
- **[[Infrastructure-Hub]]**: Real-time telemetry, model management, and **Smart Model Routing**.
- **[[Language-Intelligence]]**: LSP integration, structural verification, and the **Neural Linter**.
- **[[Security-and-Auth]]**: Identity management, **Swarm Consensus**, and secure access.
- **[[Skill-System]]**: Expanding agent capabilities with MCP tools and **Self-Repair** logic.
- **[[Hardware-Acceleration]]**: Local GPU optimization and **VRAM Pooling**.
- **[[API-Reference]]**: Documentation for the REST and WebSocket protocols.

## System Protocols

All Neurex modules adhere to the following standards:
- **Async-First**: High-concurrency execution via Python and Rust.
- **Strict Typing**: Type-safe Pydantic and TypeScript architectures.
- **Atomic State**: Resilient task graphs and persistent terminal sessions.
